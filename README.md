# harness-tweaks

Recipes for repairing and customizing the AI apps you already use.

- **Repairs** address a specific failure on tested versions. The first two cover ChatGPT desktop.
- **Tweaks** make small, reversible changes to an app’s interface or shortcuts.

## Repairs

- [Restore Local Work routing and Section actions](repairs/chatgpt-desktop/local-work-and-sections.md)
- [Reopen local conversations after a desktop rollback](repairs/chatgpt-desktop/conversation-compatibility.md)

Use the [recipe template](templates/RECIPE.md) to document a change and check it after an update.
